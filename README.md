# 智能计算记事本

离线 Windows 桌面记事本，Python + PySide6。无需账号、API 或网络服务。保留输入原文，在独立结果栏实时计算。

## Windows 用户

本次 Linux 开发环境不提供伪造或未经验证的 Windows exe。将本仓库推送到 GitHub 后，打开 **Actions → Windows executable → 最新成功运行 → Artifacts → SmartCalculatorNotepad-Windows-x64**，下载并解压，双击 `SmartCalculatorNotepad.exe`。也可以在 Actions 手动 Run workflow。构建失败时不会上传成功产物。下载 Artifacts 通常需要登录 GitHub，程序本身不需要登录。

尚未签名的程序可能触发 SmartScreen；请核对来源。最终 Windows 10/11、真实中文输入法及独立 exe 验收见验收报告。

## 开发与一键打包

需要 Python 3.12 x64（仅开发机器需要）。Windows PowerShell 在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

脚本创建虚拟环境、安装固定版本依赖、执行测试、生成 `dist/SmartCalculatorNotepad.exe`。用户运行 exe 不需要 Python。首次构建需要网络下载依赖，成品完全离线。

Linux 开发：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
.venv/bin/python run.py
```

Linux 无图形桌面时只能进行 offscreen 界面测试。

## 输入与核对

直接输入 `采购 1500+2300`、`运费 680`、`手续费 120.5`，合计为 `4,600.5`。输入无需等号，250 ms 防抖；结果栏同步滚动、不自动换行，点击结果可查看来源和手动修正。

纯数值和明确算式参与合计；金额关键词采用保守白名单。日期、时间、订单号、电话号码、身份证等标识行不计入。`商品 5件，每件30元` 可识别为 `5*30`；其他多数字或含义不明行标记待确认。比如 `苹果 30`，通过右键“指定金额”确认。规则不是通用中文理解器，不会猜测所有商品名称。

右键菜单可指定本行金额、普通数字、百分比、忽略、是否参与合计，也可指定独立计算算式而保留原文。本版本的手动修正粒度为**整行**：多数字行使用“指定本行算式”，尚不提供逐数字点选标记。自动识别可恢复自动角色；手工算式清空后重新提取。手动规则按行保存；插入删除行自动迁移，涉及不同数量行的复杂替换会清除受影响行规则，须重新核对。撤销文本不承诺恢复已清除的规则。

`【采购】` 或 `# 采购` 建立分组，标题旁显示自动小计。状态栏显示当前光标所在组小计、全文合计、文件名、保存状态和错误/待确认数。每个标题是独立分组，重复标题也不会合并。用户输入的“小计 2500”“总计 3530”不再参与合计。

## 精度与百分比

使用 Decimal，内部精度 160 位，汇总 170 位。仅显示时 ROUND_HALF_UP 到最多 4 位，整数不补小数，可关闭千分位。原文不修改。支持数字最多 100 字符、表达式最多 2048 字符和 512 token、括号最多 64 层；超限给出错误，不支持科学计数法。非常接近零的显示可能四舍五入为 0。

独立 `0.15` 显示 `15%`，默认不计入金额；0 和 1 保持普通数字。金额描述 `费用 0.15` 保持金额。`15%` 数值为 0.15。右键“指定百分比”把绝对值小于 1 的数字视为比例，其余数字除以 100。

统一采用标准数学规则：**百分号始终表示除以 100**，加减百分比不会自动按涨价或降价处理。`500+15%=500.15`，`500-15%=499.85`，`500×15%=75`，`500÷15%=3333.3333`。如需增加 15%，请明确输入 `500×(1+15%)=575`。

优先级：括号 → 一元正负号与后缀 % → 乘除 → 加减；所有二元同级运算左结合。`500+10%+5%=500.15`，`500+(10%+5%)=500.15`，`500+10%*2=500.2`。完整算式中的未带百分号小数保持普通数值：`100×0.5=50`，`500×0.15=75`；单独输入 `0.15` 的百分比显示不影响算式规则。界面不提供百分比模式切换；打开旧文档也会忽略历史模式并采用标准规则。不支持隐式乘法、货币换算或英文数学函数。

## 文件与恢复

`.scn` 是 UTF-8 JSON，保存原文、手动规则和设置。支持打开 TXT，作为未命名文档导入，避免用专用格式覆盖 TXT。导出原文 TXT、附结果 TXT 或 CSV（Excel 可读 UTF-8 BOM）。不要将导出目标选为原始文档。

自动保存默认开启：停止输入 1.2 秒后保存恢复副本及已命名文档；未命名文档也有恢复副本。文件使用同目录临时文件、flush/fsync 和原子替换。文档指纹检测外部改动，冲突时拒绝覆盖，请另存为。检测与替换之间仍有极短竞争窗口，不支持多人同时编辑。断电恢复还取决于操作系统和磁盘保障。

恢复副本位于 Qt AppDataLocation（Windows 通常为 `%LOCALAPPDATA%/SmartCalculatorNotepad` 或 `%APPDATA%/SmartCalculatorNotepad`，以系统实际路径为准），启动时询问是否恢复。不恢复则尝试最近文档。当前版本为单窗口单恢复槽；切换文档前会询问保存。关闭自动保存后仅手动保存，退出时询问，最近已保存的恢复副本仍可能存在。

## 快捷键与设置

| 快捷键 | 操作 |
|---|---|
| Ctrl+N / Ctrl+O | 新建 / 打开 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+C / V / X | 复制 / 粘贴 / 剪切 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+A / Ctrl+F | 全选 / 搜索（循环） |

设置提供浅色/深色、字体、字号、自动保存、千分位和结果栏；文档保存这些设置。窗口大小与最近文件保存在本机设置。

## 常见问题

- “待确认”：未计入金额，请右键指定角色或算式。
- “不能除以零”：修改分母；不会计入合计。
- “算式不完整”：检查括号、连续符号、未完成输入和无效字符。
- “文件已被其他程序修改”：另存为，比较两个版本；不要强制覆盖。
- 保存失败：检查目录权限和磁盘空间，保留窗口并另存为到可写目录。
- 首次启动慢：onefile 需要临时解压 Qt；后续也有解压开销，不能保证极快启动。
